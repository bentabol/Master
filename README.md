# Master's Projects — AI & Big Data (IMF Smart Education)

Coursework and case studies from my Master's in Artificial Intelligence and Big Data. Each file is an independent exercise; they are not a single connected pipeline.

## Contents

| File | Topic |
|---|---|
| `practicaM9(ClasificacionImagenes.ModeloAprendizaje).ipynb` | **Image classification with CNNs.** Data preprocessing, training a custom CNN, and Transfer Learning with **MobileNetV2** and **ResNet50**; comparison against the from-scratch model. This is the notebook referenced as my "Image Classification System with CNNs" project. |
| `casoParcticoM8(CreacionModeloSARIMA.NivelesDeConsumo).ipynb` | Time-series forecasting of consumption levels with a **SARIMA** model. |
| `PySpark_Telco_IMF_evaluacion.ipynb` | Business case on a telecom dataset solved with **PySpark** and **Hive** tables. |
| `CasoPracticoIAparaEMPRESAS.ipynb` | Multi-armed bandit (epsilon-greedy) exercise to optimize which banner image maximizes clicks — explore/exploit trade-off. |
| `CasoPractico(UsoAZURE).docx` | Case-study brief on an **Azure** serverless analytics architecture for a small company (design exercise, not tied to the CNN notebook). |
| `casoPractico(PrediccionTraficoCeldas).docx` | Case-study brief on cell-traffic prediction (assignment statement). |

## Note

These are graded coursework deliverables, kept here as evidence of hands-on work with CNNs/Transfer Learning, time series, Spark and applied ML — not a polished production repo. For an end-to-end engineered project, see [`multi-agent-llm`](https://github.com/bentabol/multi-agent-llm).
